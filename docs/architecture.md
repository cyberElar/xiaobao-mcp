# 系统结构与会话

本服务面向单个拥有者。所有获授权的 OAuth 客户端使用同一个校宝账号和可选绑定的微软账号。两个账号独立绑定。服务不提供多用户隔离；上游写入只通过明确列出的写入工具开放。

```text
ChatGPT → HTTPS 反向代理 → /mcp → 查询工具 → 校宝 HTTP 客户端
                              ├→ 微软查询 → Microsoft Graph
                              ├→ 附件下载 → PDF 解析线程
                              ├→ 写入工具 → 请求去重记录 → 上游固定写入接口
                              └→ GPA 与成绩预测
```

## 独立授权

ChatGPT 使用本服务签发的 OAuth 令牌。校宝客户端使用独立的校宝 Cookie。服务不会把校宝凭据放入工具参数或返回结果。

微软客户端使用独立的 Microsoft OAuth 令牌。设备代码授权可通过手机完成，不需要浏览器扩展常驻。微软授权的绑定、刷新和权限边界见[微软授权与 Teams](microsoft.md)。

OAuth 路由使用官方 MCP TypeScript SDK。SDK 负责客户端注册、请求校验、PKCE 校验和发现端点。`src/auth.ts` 负责拥有者授权、授权码和令牌存储。

拥有者在授权页输入 `.env` 中的 `OWNER_KEY`。授权页同时校验浏览器 Cookie、一次性事务和请求来源。授权码有效期为 60 秒，授权事务有效期为 5 分钟。

访问令牌有效期最长为 1 小时。刷新令牌轮换后，旧刷新令牌不能再次使用。检测到旧刷新令牌重用时，服务撤销同一授权产生的令牌。授权会话最长为 30 天。

服务在 `secrets/oauth.json` 中保存客户端和令牌状态。访问令牌与刷新令牌只保存 SHA-256 摘要。SDK 注册的机密客户端密钥保存在同一私有文件中。文件权限为 `0600`。重启保留客户端和令牌；未完成的授权事务和授权码会失效。更换 `OWNER_KEY` 会清空原有授权状态。

MCP 路径为 `/mcp`。服务为每个 POST 请求创建独立的 SDK 服务器与传输对象，不分配 MCP 会话 ID。所有 MCP 请求都需要 `schoolis.read` 权限，健康检查不需要授权。这个服务权限覆盖校宝及已绑定微软账号的全部只读工具。

写入工具还要求 `schoolis.write`，并在回调中核对 SDK 传递的已验证令牌权限。工具声明包含相同的 OAuth 权限元数据。只读令牌调用写入工具时返回权限错误和 OAuth 重新授权提示。刷新令牌不能扩大原授权范围；写入权限应通过新的授权码流程取得。

MCP JSON 请求体上限为 8 MB，用于容纳最多 5 MB 文件的 base64 编码。服务先检查 Host、MCP 令牌和速率限制，再解析 MCP 请求体。OAuth 注册和授权路由保留各自的解析与大小限制。

## 校宝登录

服务提供两种绑定方式：

- 终端登录：读取账号与密码，完成验证码后保存校宝会话。
- Cookie 导入：读取浏览器导出的 Cookie 数组或包含 `cookies` 的存储文件。

两种绑定方式都先读取学生身份和非空学期列表，成功后才替换现有会话。账号密码不会出现在命令行参数中。导入的会话与凭据文件都应放在 Git 忽略目录中。

截至 2026-10-15，公开登录脚本显示以下协议：

1. GET `/api/MemberShip/GetStudentCaptchaForLogin` 获取验证码要求。
2. POST `/api/MemberShip/Login?captcha=...` 提交登录信息。
3. 请求体包含 `name`、`password`、`timestamp`、`isWeekPassword` 和 `LanguageType`。
4. `password` 为 `MD5(大写 MD5(原密码) + 秒级时间戳)` 的大写十六进制值。

协议来自登录页公开脚本。已绑定的账号会话通过了身份与真实业务查询验证。校宝通过 HTTPS 传输登录信息。

本服务在无会话请求中观测到：学生信息接口返回 HTTP 200，业务状态为 `999901`。客户端同时检查 HTTP 状态、JSON 格式和业务状态。`999901` 与 `999902` 会触发会话失效错误。

首次验证成功后，客户端在会话中固定 `loginName`。身份变化会停止查询。凭据所属账号与固定身份不符时，客户端也会停止登录。

使用 `--remember` 登录时，服务把原密码保存到 `secrets/schoolis.json`，用于会话失效后的自动登录。默认登录只保存 Cookie。自动登录遇到验证码时停止，并提示人工绑定。自动登录失败后，服务在 5 分钟内不再尝试，避免连续错误登录。

服务不保证永久免登录。Cookie 过期、学校变更登录协议、验证码或账号状态变化，都可能要求用户重新绑定。

## 请求与缓存

校宝客户端只访问代码中列出的接口。工具参数不能指定任意地址。客户端不跟随重定向，避免把 Cookie 转发到其他主机。

客户端默认超时为 15 秒，单次上游响应最多为 5 MB。查询缓存默认保留 60 秒，最多保存 200 项。配置 `CACHE_TTL_SECONDS=0` 可关闭缓存。会话替换或重新登录时，客户端清空缓存。

作业与考试工具每次读取一页，单页最多为 100 项。返回的 `pagination` 描述当前页，不代表全量数据。课表查询最多跨 31 天。

统计查询使用独立的筛选项接口。客户端把统计分页参数序列化为 `page.pageIndex` 和 `page.pageSize`。升学工具先读取当前账号的档案 ID，没有档案时停止；工具不接受外部档案 ID。升学资料和文书使用只读 POST 查询，不接入保存、删除或上传接口。

附件读取先查询作业详情，再按 ID 和来源匹配附件。下载只允许 `cdn.schoolis.cn` 的 HTTPS 地址，不发送校宝 Cookie，也不跟随重定向。服务最多下载 5 MB，通过响应类型和文件头校验 PDF，通过 UTF-8 解码校验纯文本。PDF 文字提取使用 `unpdf`，在限制内存和运行时间的独立线程中执行。文件内容不写入磁盘，不缓存，不执行。

服务不记录请求体、密码、Cookie、令牌或校宝返回正文。工具会移除凭据字段。学校返回的任务说明和附件名称属于不可信业务文本，不能作为执行指令。

微软查询客户端只对固定的 Graph 路径发送 GET 请求。写入客户端另外允许本人提交的指定 POST、受限资源目录内的文件 PUT，以及个人日历事件 POST。每种写入校验相应微软权限。分页地址应保持 Graph 域名及原始接口路径；工具使用签名游标绑定账号、接口和筛选条件。微软令牌不会发送到校宝、文件 CDN 或分页重定向地址。Teams 和日历文本也属于不可信业务数据。

写入记录保存在 `WRITE_STATE_FILE`，使用原子替换和 `0600` 权限。相同账号、动作和 `requestId` 的请求只执行一次，参数变化会被拒绝。资源锁避免同一作业同时上传与提交。写入记录和上传凭据的限制见[作业写入与文件上传](writes.md)。

## 当前限制

- 只绑定一个校宝账号和一个可选微软账号；不同 OAuth 客户端共享这些账号。服务不自动判断两个账号是否属于同一学生。
- 已验证账号身份、学期、科目、作业与详情、课表、成绩分类、GPA 和预测基线。当前查询范围内没有考试，考试详情尚未实测。
- 服务新增工具后，客户端需要刷新工具列表。
- 成绩分类字段不符合已知格式时，服务返回格式错误，不猜测字段含义。
- 动态成绩详情不可用时，服务尚不从作业和考试详情重建成绩。
- 升学档案不存在时的返回已经实测；有档案时的任务、资料和文书分支仅通过测试样本验证。
- 附件文字提取不提供扫描图片识别，不能替代原文件排版。
- 学校资源库、学生表单和问卷仅接入功能状态，没有接入记录列表。
- Teams 与 Outlook 工具需要独立微软授权。写入另需相应上游权限；学校策略、撤销授权或验证码要求可能导致重新登录。
- 写入是否可用取决于学生身份、作业状态和学校政策。校宝提交后会尝试回读确认；失败时返回校验未完成，不自动重复提交。
- 写入流程尚未使用真实作业或日历执行端到端验证；自动化测试使用模拟上游。
- 聊天、SharePoint 文件下载、日历修改／删除和隐藏成绩反推尚未接入。
- OAuth 状态使用单进程文件存储。部署时只运行一个服务实例。
